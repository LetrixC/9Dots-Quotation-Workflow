How it works

This page is a clickable prototype for approval. The production build keeps the same screens and replaces the simulated parts with these services.

GitHubSource code and change history. Every merge to main deploys automatically.
Azure Static Web AppsHosts the site and a small API. Free tier is enough for internal use.
Microsoft 365 sign-inOnly 9Dots staff accounts can open the site (Entra ID).
SharePointStores templates (with SharePoint version history), the sign-off list, and generated contracts per client.
Word generationThe API fills the template's placeholders and inserts the SOW table, keeping your exact formatting.
DocuSign eSignatureSends the contract with signature tabs in signing order and reports status back. Needs an API integration key.

Simulated in this prototype

  • Nothing is saved: refreshing the page resets to the sample data.
  • No emails are sent. The tracker lets you step through signatures by hand.
  • SharePoint paths are shown as they would appear, but no files are written.
  • All accounts and people are examples, not real contacts.
